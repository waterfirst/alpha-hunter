# 기획 초안 — 성장률을 통과한 기업, 현금도 통과했을까

상태: 발행 전 조사 기획 / 투자 권유 아님  
작성일: 2026-11-07

## 질문

매출과 영업이익 성장 조건을 통과한 기업은 영업현금흐름과 운전자본의 움직임에서도 같은 품질을 보이는가.

## 2차 심사 항목

1. 매출 성장률 대비 매출채권 증가율
2. 매출 성장률 대비 재고 증가율
3. 영업현금흐름과 순이익의 차이
4. 분기 말 일회성 운전자본 변동 여부
5. 공시 원문에서 확인되는 결제 조건·재고·회수 위험

## 자료·방법

- 기업별 같은 기준일의 사업보고서·분기보고서·감사보고서 원문을 사용한다.
- 선별 규칙, 제외 기준, 기준일을 발행 전에 고정한다.
- 숫자는 원문 표와 대조하고, 계산식과 단위를 공개한다.
- 개별 종목의 매수·매도·목표가·손절가를 제시하지 않는다.

## 아직 말할 수 없는 것

- 어떤 기업이 현금흐름 기준을 통과하는지
- 현금흐름 차이가 거래 조건 악화인지 단순 시점 차이인지
- 투자 성과 예측

## 발행 차단 조건

- 공시 원문 또는 기준일을 확보하지 못한 경우
- 매출·채권·재고·현금흐름 기간이 서로 다른 경우
- 사실과 해석, 추정을 구분하지 못한 경우
